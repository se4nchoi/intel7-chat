기능 도움말

대나무숲에서 사용할 수 있는 기능입니다.

💬 채널, DM과 읽지 않은 메시지

사이드바에서 채널을 선택하거나 사용자 이름을 눌러 1:1 DM을 시작합니다. 숫자 배지는 아직 읽지 않은 메시지 수이며, 대화를 열면 읽음 처리됩니다.

DM은 당사자만 볼 수 있지만 서버에 영구 저장되고 저장 데이터는 암호화되지 않습니다. 민감정보는 공유하지 마세요.

↩️ 답장, 반응, 고정과 수정

메시지 옆 동작 버튼으로 답장, 이모지 반응, 고정을 사용할 수 있습니다. 내 메시지는 수정할 수 있습니다. 관리자는 공개 채널 메시지를 숨기거나 다른 채널로 이동할 수 있습니다.

🔔 알림과 음소거

상단 🔔는 전체 소리·데스크톱 알림·방해 금지를 설정합니다. 대화 제목 옆 🔔는 현재 채널 또는 DM만 음소거합니다. 음소거해도 읽지 않은 메시지 배지는 유지됩니다.

🔎 검색과 이전 기록

대화 제목 옆 🔎에서 현재 대화 또는 접근 가능한 전체 기록을 검색합니다. 상단의 “이전 메시지 더 불러오기”로 오래된 기록을 추가로 불러옵니다.

@ 멘션과 메시지 작성

@ 뒤에 사용자를 선택하면 해당 사용자에게 중요 알림이 전달됩니다. Enter로 전송하고 Shift+Enter로 줄을 바꿉니다. 입력창 위 도구로 Markdown 서식을 적용할 수 있습니다.

📎 파일

＋ 버튼으로 파일을 첨부합니다. 데스크톱에서는 파일을 대화 영역에 끌어 놓을 수도 있습니다. 메시지를 보내기 전에 업로드가 끝나야 합니다.

🧠 퀴즈, 점수와 복습

첫 제출만 난이도별 점수와 랭킹에 반영됩니다. 제출 후 정답과 해설이 공개되므로 재풀이는 점수를 주지 않고 숙달 상태만 기록합니다. STREAK은 그날 배정된 오늘의 퀴즈를 풀 때 유지됩니다.

공정한 랭킹을 위해 첫 제출 전에는 AI나 외부 정답을 붙여넣지 마세요. 문제 오류는 관리자에게 알려 주세요.

🧩 문제집 만들기

생성된 JSON을 저장하면 초안이 됩니다. 검토 요청 후 관리자가 수정·승인하면 공용 문제 풀에 추가됩니다. AI가 만든 문항도 정답, 보기, 해설과 출처를 직접 확인한 뒤 제출해야 합니다.

⌨️ 다시 도움받기

상단의 ? 또는 채팅에 !도움을 입력해 이 안내를 다시 열 수 있습니다.
